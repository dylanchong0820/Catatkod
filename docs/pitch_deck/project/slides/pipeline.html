How it works

Shorthand to ICD-11 in five steps

1. Note

Nurse types in Malay, English or both

2. Normalise

Expand shorthand; mark denials and doubts

3. Tier 1

Phrase rules plus trained model: 121 common codes

4. Tier 2

Search all ~17,000 ICD-11 diagnosis codes

5. Confirm

Nurse reviews every code before saving

Coding rule built in: symptoms that belong to a diagnosis are not coded twice (tonsillitis covers sore throat).

First we clean up the shorthand and mark anything that’s denied or only suspected. Then our trained model and Malay–English phrase rules suggest codes from 121 common primary-care conditions. For anything rarer, we search the whole WHO ICD-11 catalogue. We follow standard coding practice: a diagnosis covers its usual symptoms. And the nurse always has the final say.
