CatatKod never codes on its own. It suggests, shows its evidence, and the nurse decides. The API stores no note text, only a fingerprint and timing, and the model runs locally, so patient notes don’t have to leave the clinic. This prototype uses only synthetic data; a real deployment needs a PDPA review and validation by clinicians.
